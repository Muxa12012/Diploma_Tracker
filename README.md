# Трекер/детектор домашних животных с возможностью обучения на определённых животных, а также с возможностью определения основных классов животных.
## Что есть сейчас:
1. Несколько обученных моделей, способных определять лица людей и основных домашних животных
2. Инструмент для создания датасетов под модель YOLO (в проекте используется YOLO26) (инструменты до конца не протестированы, точно работате ручная разметка по камере):
    - Возможность создавать датасет по изображениям видеопотока с ручной разметкой;
    - Возможность создавать изображения для датасета с камеры с использованием предобученной модели YOLO;
    - Возможность создавать датасет по загруженным изображениям с использованием модели YOLO;
    - Возможность превращения видео в датасет с использованием предобученной модели YOLO;
    - Возможность редактировать `data.yaml` файл с класса для обучения конечной модели с добавлением и удалением классов;
    - Возможность переименовывать классы в датасете.
3. Инструмент для аугментации изображений для расширения датасета
4. Скрипты для обучения моделей YOLO
5. Скрипт, позволяющий запустить одну из предобученных моделей для распознавания с видеокамеры устройства (может потребоваться разрешение антивируса)

## Что планируется добавить:
1. Запуск и обучение конечной модели или моделей:
    - Если получится реализовать добавление и обучение кастомной головы для детекции, тогда будет использоваться одлна модель, если нет, то тогда будет использованы 2 модели - одна генерализованная со всеми классами и одна специальная, которая будет распознавать только пользовательские классы
2. Централизованный скрипт, позволяющий запускать остальные подпроцессы/подпрограммы
3. Дальнейшее тестирование и доработка модели при необходимости (создание датасета, переименовывание и удаление классов).
