# Practice_Diploma_Tracker - Главный скрипт управления

## Обзор

`run_project.py` - это универсальный скрипт для управления всеми основными компонентами проекта компьютерного зрения с использованием YOLO. Скрипт предоставляет удобное цветное меню для запуска всех этапов работы с проектом.

## Быстрый старт

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск главного меню
```bash
python run_project.py
```

## Основные возможности

### 1. Создание датасета
- Создание датасетов YOLO из различных источников:
  - С камеры в реальном времени
  - Из существующих изображений
  - Из видеофайлов
- Управление классами (удаление, переименование, статистика)
- Автоматическая аугментация датасетов

### 2. Обучение модели
- Обучение моделей YOLO на ваших датасетах
- Поддержка различных архитектур YOLO
- Мониторинг процесса обучения

### 3. Детекция объектов
- Запуск обученной модели для детекции в реальном времени
- Работа с веб-камерой
- Отображение FPS и результатов детекции

### 4. Каскадное обнаружение
- Последовательное применение двух моделей: targeted (целевой объект) и general (все объекты)
- Фильтрация пересекающихся bounding boxes по IoU
- Разные цвета визуализации для каждой модели
- Поддержка работы с веб-камерой и видеофайлами

### 5. Аугментация данных
- Геометрические преобразования (поворот, сдвиг, отражение)
- Цветовые преобразования (яркость, контраст, насыщенность)
- Шумовые аугментации
- Сохранение bounding boxes при аугментации

## Дополнительные возможности

### Поддержка кириллицы в консоли
- Корректное отображение русских символов в меню и выводах
- Устранение проблем с кодировкой в Windows и Linux

### Единая структура датасетов
- Все датасеты сохраняются в стандартизированной папке `datasets/camera_dataset`
- Автоматическое создание необходимых поддиректорий (images, labels)

### Умный выбор классов
- Классы выбираются только из `data.yaml` датасета
- Автоматическое определение доступных классов
- Валидация введённых пользователем классов

### Маппинг классов между пользовательскими именами и классами модели YOLO
- Поддержка удобных имён классов (например, "кошка", "собака")
- Автоматическое преобразование в индексы модели YOLO
- Обратный маппинг для понятного вывода результатов

### Ограничение детекции на уровне модели для повышения производительности
- Фильтрация классов непосредственно в модели YOLO
- Снижение вычислительной нагрузки за счёт игнорирования нерелевантных классов
- Ускорение инференса без потери точности на целевых объектах

## Расширенные возможности

### Управление классами датасета
Скрипт `run_dataset_creator.py` (запускается через опцию 1) предоставляет:
- Удаление классов с полным циклом
- Переименование классов
- Просмотр статистики классов
- Автоматическую коррекцию меток

### Конфигурация аугментации
Настройки аугментации находятся в `augmentations/aug_config.yaml`:
- Геометрические преобразования
- Цветовые корректировки
- Параметры шума
- Настройки вывода

### Валидация датасетов
Для проверки целостности датасетов YOLO используйте скрипт `validate_dataset.py`:

```bash
# Проверить конкретный датасет
python validate_dataset.py "путь/к/датасету"

# Показать все доступные датасеты
python validate_dataset.py --list

# Проверить все датасеты в директории
python validate_dataset.py --all
```

**Проверяемые аспекты:**
1. **Структура data.yaml** - наличие обязательных ключей (nc, names), корректность типов
2. **Структура директорий** - наличие папок images/labels для train/val/test
3. **Соответствие файлов** - проверка, что для каждой аннотации есть изображение и наоборот
4. **Корректность аннотаций** - формат YOLO (class_id x_center y_center width height), значения в диапазоне [0,1]
5. **Распределение по классам** - статистика использования каждого класса

## Устранение неполадок

### Проблема: "Файл не найден"
**Решение**: Убедитесь, что все необходимые файлы существуют:
```bash
python run_project.py
# Выберите опцию 5: "Информация о проекте"
```

### Проблема: "Зависимости не установлены"
**Решение**: Установите все зависимости:
```bash
pip install -r requirements.txt
```

### Проблема: "Камера не работает"
**Решение**: Проверьте подключение камеры и права доступа
