# Целевое обучение модели YOLO

## 📋 Обзор

Обновленный скрипт `train_target_yolo.py` предоставляет расширенные возможности для обучения моделей YOLO с поддержкой:

1. **Выбора датасета** - аугментированный или неаугментированный
2. **Перезаписи моделей** - автоматическое удаление старых версий
3. **Целевого сохранения** - все модели сохраняются в папку `targeted_yolo`

## 🚀 Быстрый запуск

### Через главное меню:
```bash
python run_project.py
# Выберите опцию 2: "Обучение модели"
# Выберите скрипт 2: "train_target_yolo.py"
```

### Прямой запуск интерактивного скрипта:
```bash
python train_target_yolo.py
```

### Запуск с аргументами командной строки:
```bash
python train_target_yolo_simple.py --dataset augmented --epochs 30 --batch 8 --name my_model
```

## 📊 Основные возможности

### 1. Выбор датасета
- **Аугментированный датасет** (`datasets/camera_dataset_augmented`)
- **Неаугментированный датасет** (`datasets/camera_dataset`)
- **Пользовательский датасет** (любой путь с файлом `data.yaml`)

### 2. Управление моделями
- **Автоматическая перезапись** - удаление старых моделей перед обучением
- **Целевая папка** - все модели сохраняются в `targeted_yolo/`

### 3. Настройка параметров
- **Количество эпох** (по умолчанию: 50)
- **Размер изображения** (по умолчанию: 640)
- **Размер батча** (по умолчанию: 16)
- **Имя модели** (по умолчанию: `targeted_yolo_model`)

## 🎯 Рабочий процесс

### Шаг 1: Подготовка датасетов
Убедитесь, что датасеты существуют:
```bash
# Проверка существования датасетов
ls -la datasets/
```

Если датасеты отсутствуют, создайте их:
1. Запустите `run_project.py`
2. Выберите опцию 1: "Создание датасета"
3. Создайте датасет с камеры или из изображений
4. При необходимости выполните аугментацию (опция 4)

### Шаг 2: Запуск обучения
```bash
# Интерактивный режим (рекомендуется для первого использования)
python train_target_yolo.py

# Или через главное меню
python run_project.py
# 2 → 2 → Следуйте инструкциям
```

### Шаг 3: Мониторинг обучения
Во время обучения отображается:
- Прогресс по эпохам
- Метрики точности (mAP, precision, recall)
- Время выполнения
- Сохранение промежуточных результатов

### Шаг 4: Использование обученных моделей
Обученные модели сохраняются в:
```
targeted_yolo/
├── targeted_yolo_model_best.pt    # Лучшая модель
├── targeted_yolo_model_last.pt    # Последняя модель
└── targeted_yolo_model/          # Полные результаты обучения
    ├── args.yaml                 # Параметры обучения
    ├── results.png               # Графики результатов
    ├── weights/                  # Веса моделей
    │   ├── best.pt
    │   └── last.pt
    └── ...                       # Другие файлы результатов
```

## ⚙️ Параметры командной строки

### Для `train_target_yolo_simple.py`:

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--dataset` | Тип датасета: `augmented`, `original`, `custom` | `augmented` |
| `--dataset-path` | Путь к датасету (только для `custom`) | - |
| `--model` | Путь к предобученной модели | `yolo26n.pt` |
| `--epochs` | Количество эпох | `50` |
| `--imgsz` | Размер изображения | `640` |
| `--batch` | Размер батча | `16` |
| `--name` | Имя модели для сохранения | `targeted_yolo_model` |
| `--force` | Перезаписать существующие модели | `False` |

### Примеры использования:

```bash
# Обучение на аугментированном датасете с параметрами по умолчанию
python train_target_yolo_simple.py

# Обучение на оригинальном датасете с 30 эпохами
python train_target_yolo_simple.py --dataset original --epochs 30

# Обучение на пользовательском датасете с указанием пути
python train_target_yolo_simple.py --dataset custom --dataset-path datasets/my_dataset --name custom_model

# Обучение с перезаписью существующих моделей
python train_target_yolo_simple.py --force --epochs 100 --batch 32
```

## 🐛 Устранение неполадок

### Проблема: "Датасет не найден"
**Решение**: Создайте датасет или проверьте путь:
```bash
# Проверьте существование датасетов
ls -la datasets/camera_dataset/
ls -la datasets/camera_dataset_augmented/

# Если отсутствуют, создайте через run_dataset_creator.py
python run_dataset_creator.py
```

### Проблема: "Файл data.yaml не найден"
**Решение**: Убедитесь, что в датасете есть файл `data.yaml`:
```bash
# Проверьте структуру датасета
find datasets/camera_dataset -name "data.yaml"
```

### Проблема: "Недостаточно памяти"
**Решение**: Уменьшите размер батча:
```bash
python train_target_yolo_simple.py --batch 8 --imgsz 320
```

### Проблема: "Модель не перезаписывается"
**Решение**: Используйте флаг `--force`:
```bash
python train_target_yolo_simple.py --force
```

## 📈 Советы по обучению

### Для лучших результатов:
1. **Используйте аугментированный датасет** для улучшения обобщения
2. **Начинайте с малого количества эпох** (20-30) для тестирования
3. **Увеличивайте размер батча** при наличии достаточной памяти
4. **Экспериментируйте с размерами изображений** (320, 640, 1280)
5. **Сохраняйте разные версии моделей** с разными именами

2. Использовать флаг `--force` для перезаписи
3. Обновить пути в скриптах детекции
